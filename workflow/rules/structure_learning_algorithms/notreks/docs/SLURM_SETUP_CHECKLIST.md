# NOTREKS SLURM Setup Checklist

- [ ] GitHub SSH works on the cluster.
- [ ] Repository cloned from `git@github.com:fbleile/benchpress.git`.
- [ ] Branch `add-notreks-module` checked out.
- [ ] Conda or micromamba available.
- [ ] Environment `benchpress-notreks` created on the cluster.
- [ ] NOTREKS tests pass.
- [ ] Apptainer is available.
- [ ] SLURM smoke config generated.
- [ ] Snakemake dry-run passes.
- [ ] SLURM smoke submitted with the Snakemake driver.
- [ ] Smoke validation finishes.
- [ ] Smoke results selected.
- [ ] True grid prepared.
- [ ] True validation submitted only after smoke is clean.

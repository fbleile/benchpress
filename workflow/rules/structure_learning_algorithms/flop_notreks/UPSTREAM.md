fitting and reinsertion, complete-refit ancestry-cone promotions, canonical
signature compression at search plateaus, fixed-signature Version A,
alternating full-refit Version B, deterministic seeded search, diagnostics, and the
`flopsearch.flop_notreks` Python API. Vanilla Benchpress FLOP continues using
the unmodified released package.
